Docker & さくらのクラウドAppRun ハンズオン

1. はじめに

このハンズオンでは、クラウド上のUbuntuサーバにDocker環境を構築し、基本的なコンテナ操作を学びます。後半では、作成したコンテナを**さくらのクラウド「AppRun」**を使って、インフラ管理不要（サーバレス）でインターネットに公開する一連の開発フローを体験します。

本日のゴール
① 踏み台経由で実習用Ubuntuに接続し、DockerをインストールしてWebサーバを立ち上げる。
② AppRunを使って、自分の名前と色を設定した「ネームボード」コンテナをデプロイし、クラス全体のボードと連携させる。

2. 踏み台サーバへの接続

今回の実習環境はセキュリティを高めるため、直接アクセスすることができません。まずは入り口となる「踏み台サーバ」にSSH接続します。

ターミナル（WindowsはPowerShell、Macはターミナル）を開き、以下のコマンドを実行してください。

bash 
ssh ubuntu@<踏み台サーバIPアドレス>

パスワードを求められた場合は、教員から指示されたパスワードを入力します。（※入力中、画面に文字は表示されません）

3. Docker環境の構築

踏み台サーバを経由して、実際にDockerを動かす演習用のUbuntuサーバに接続し、Dockerをインストールします。

3.1 実習用サーバへのログイン

踏み台サーバにログインした状態のまま、続けて実習用サーバにSSH接続します。

bash 
ssh ubuntu@<指定されたIPアドレス>
ログインの確認
ログイン後、ターミナルの入力行（プロンプト）の表示が ubuntu@jump-host-** から ubuntu@server**（**は数字）に変わっていることを確認してください。表示が変わっていれば、実習用サーバへの接続は成功です。

3.2 Dockerのインストール

Ubuntuのパッケージを最新化し、Dockerの公式インストールスクリプトを実行します。

bash 
curl -fsSL https://get.docker.com -o install.sh
sudo sh ./install.sh

3.3 ユーザー権限の設定

現在の ubuntu ユーザーが sudo なしでDockerコマンドを実行できるように、グループに追加します。

bash 
sudo usermod -aG docker ubuntu
重要: グループ設定の反映には再ログインが必要です
設定を反映させるため、ターミナルで以下の exit コマンドを実行して一度ログアウトしてください。
bash 
exit
注意: 踏み台サーバに戻ります
exit を実行すると、手前の踏み台サーバに戻ります。
そのため、もう一度以下のコマンドを実行し、実習用サーバに再ログインしてください。
bash 
ssh ubuntu@<指定されたIPアドレス>

再ログイン後、以下のコマンドを実行してDockerのバージョンが表示されれば設定は完了です。

bash 
docker -v

4. コンテナの起動実験

環境が整ったので、世界で一番有名なテストコンテナを動かしてみましょう。

bash 
docker run hello-world

Hello from Docker! というメッセージが表示されれば、正常にDockerが動作しています。

5. Apache(Webサーバ)の起動

次に、実際のWebサーバである「Apache」をコンテナとして立ち上げます。

5.1 コンテナの起動（バックグラウンド実行）

以下のコマンドを実行します。ホストの8080番ポートをコンテナの80番に繋いでいます。

bash 
docker run -d -p 8080:80 --name my-apache httpd

5.2 動作確認

ブラウザを開き、http://<指定されたIPアドレス>:8080 にアクセスしてください。「It works!」と表示されれば成功です。

5.3 コンテナの停止と削除

確認が終わったら、起動中のコンテナを停止し、削除してリソースを解放します。

bash 
docker stop my-apache
docker rm my-apache

6. さくらのクラウドAppRun ハンズオン

ここまではUbuntuサーバ上でDockerを動かしました。しかし実際のサービス運用では、「サーバのOSアップデート」や「セキュリティ対策」などのインフラ管理が大変になります。

そこで、「コンテナイメージを渡すだけで、あとはクラウドが勝手に自動運用してくれる」というサーバレス技術である「AppRun」を体験します。

プロジェクト: クラス・ネームボード
今回は、各自が自分の名前と好きな色を表示するコンテナをAppRunにデプロイします。デプロイされたURLを集約サイトに登録すると、教室のスクリーンに全員のボードがリアルタイムで表示されます。

7. AppRunへのデプロイ手順

7.1 コントロールパネルへログイン

ブラウザでさくらのクラウドコントロールパネルにアクセスし、教員から配布されたアカウント情報でログインします。

7.2 アプリケーションの作成

左側メニューから「AppRun（共用型）」を選択し、「追加」ボタンをクリックします。以下の通り設定してください。

設定項目 入力値
アプリケーション名 my-nameboard (※任意の英数字)
コンテナイメージ kosen-handson.sakuracr.jp/nameboard:latest
ポート設定 8080
最小スケール数 0 (※アクセスがないと自動停止してコストを節約します)
最大スケール数 1

7.3 【重要】環境変数の設定（タブ切り替え）

コンテナのコードを直接書き換える代わりに、環境変数を使ってWebアプリの表示（名前や好きな色、所属するグループ名）をカスタマイズします。

設定タブ切り替えの手順
① AppRun作成画面の「コンテナ構成」エリアを見ると、最初は コンテナ タブが選択されています。
② その右側にある 変数 タブ をクリックして切り替えてください。

「変数」タブに切り替えたら、設定エリアに以下のペア（3つの設定）を追加してください。

  • キー：MY_NAME / 値：自分の名前（ニックネーム可）
  • キー：MY_COLOR / 値：好きなカラーコード（例: #ff9900 や blue）
  • キー：MY_GROUP / 値：自分の所属グループ名（例: A組、1班 など）

7.4 デプロイと確認

「作成」をクリックしてデプロイを開始します。完了すると https://xxx.apprun.sakura.ne.jp という専用URLが発行されるので、クリックして自分のネームボードが表示されるか確認してください。

7.5 親サイトへの登録

自分のAppRun URLをコピーし、教員が提示したダッシュボード（親サイト）の登録欄に貼り付けて「参加する」を押してください。教室のスクリーンにあなたのボードが出現します！

8. 環境の片付け

パブリッククラウド環境は、リソースを起動している間コストが発生します。ハンズオンが終了したら、無駄なリソースを消費しないように必ず片付けを行いましょう。

  1. さくらのクラウドコントロールパネルのAppRun画面を開く。
  2. 作成したアプリケーション（my-nameboard）を選択する。
  3. 右上または下部にある「削除」ボタンをクリックし、アプリケーションを完全に削除する。

以上で、Dockerからクラウドサーバレスへの一連のハンズオンは終了です。お疲れ様でした！
